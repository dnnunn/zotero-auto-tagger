# Zotero Auto-Tagger

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Zotero](https://img.shields.io/badge/Zotero-7+-red.svg)](https://www.zotero.org/)
[![Version](https://img.shields.io/badge/version-0.3.0-blue.svg)](https://github.com/dnnunn/zotero-auto-tagger/releases)

Automatically generate keyword tags for your Zotero library items using PubMed and a **local** LLM. No API keys, no per-item cost, and nothing leaves your machine.

## ✨ Features

- **🧬 PubMed Integration**: Automatically fetches MeSH terms and author keywords for biomedical literature
- **🤖 Local LLM Fallback**: Generates tags for non-biomedical content (books, reports, theses, etc.) via [Ollama](https://ollama.com) — runs on your own hardware
- **📚 Universal Coverage**: Works with any item type in your Zotero library
- **⚡ Batch Processing**: Tag multiple items at once
- **💰 Free & Private**: No API key, no per-token billing, no data sent to a third party
- **🏷️ Namespaced Tags**: LLM tags are prefixed (`ai: `) and marked automatic, so they never merge with PubMed MeSH terms and can be bulk-removed
- **🎯 Smart Prioritization**: Tries PubMed first for items with DOI/PMID, falls back to AI when needed

## 🚀 What's New in v0.3.0

**Breaking: tagging is now local. The Claude API integration has been removed.**

- **Local by default**: tags are generated by [Ollama](https://ollama.com) on your machine — no API key, no cost, no data leaving your computer
- **Configurable model**: defaults to `qwen3:8b`; point it at any Ollama model you have pulled
- **Namespaced tags**: LLM-generated tags now carry an `ai: ` prefix and are stored as *automatic* tags, so they stay distinguishable from PubMed MeSH terms and can be removed in bulk
- **Reasoning-model safe**: `<think>` blocks are stripped, so chain-of-thought never ends up as tags
- **Migration**: any previously stored Anthropic API key is cleared from your preferences on first run
- **Slimmer**: removed ~2,300 lines of duplicated dead code; the packaged extension dropped from 17 files to 9

## 📋 Requirements

- Zotero 7 or higher
- [Ollama](https://ollama.com) running locally, with a model pulled:
  ```bash
  ollama pull qwen3:8b
  ```
- PubMed API key (optional, enhances biomedical queries)

## 🔧 Installation

1. Download the latest `.xpi` file: [zotero-auto-tagger.xpi](https://github.com/dnnunn/zotero-auto-tagger/releases/download/v0.2.1/zotero-auto-tagger.xpi)
2. In Zotero: Tools → Add-ons → Gear icon → Install Add-on From File
3. Select the downloaded `.xpi` file
4. Restart Zotero

## ⚙️ Configuration

### Configuration

All settings are optional — the defaults work with a standard Ollama install.

1. Open **Zotero → Settings → Advanced → Config Editor**
2. Search for `autoTagger`:

| Preference | Default | Purpose |
|---|---|---|
| `extensions.autoTagger.ollamaUrl` | `http://localhost:11434` | Where Ollama is listening |
| `extensions.autoTagger.ollamaModel` | `qwen3:8b` | Any model you have pulled |
| `extensions.autoTagger.aiTagPrefix` | `ai: ` | Prefix for LLM-generated tags |
| `extensions.autoTagger.pubmedApiKey` | *(none)* | Optional NCBI key for higher rate limits |

```javascript
// Example: use a larger model
Services.prefs.setCharPref('extensions.autoTagger.ollamaModel', 'qwen2.5:32b');
```

## 📖 Usage

1. Select one or more items in your Zotero library
2. Right-click → "Auto-Tag Selected Items"
   
   OR
   
   Tools → "Auto-Tag Items"
3. The plugin will:
   - Check for DOI/PMID and try PubMed first
   - Fall back to the local LLM for items without PubMed data
   - Add generated tags to your items
   - Show a summary of results

## 🏗️ How It Works

### For Biomedical Content
- Searches PubMed using DOI or PMID
- Extracts MeSH terms and author-provided keywords
- Adds standardized medical subject headings

### For Everything Else
- Analyzes title, abstract, authors, and metadata
- Uses a local LLM to understand content and context
- Generates 5-10 relevant keyword tags
- Focuses on main topics, methodologies, and key concepts

## 💡 Examples

**Biomedical Article**: 
- Input: Article with DOI about cancer research
- Output: MeSH terms like "Neoplasms", "Cell Proliferation", "Apoptosis"

**Book Chapter**:
- Input: Chapter about machine learning in healthcare
- Output: AI-generated tags like "Machine Learning", "Healthcare Analytics", "Predictive Modeling"

## 🛠️ Development

### Building from Source

```bash
# Clone the repository
git clone https://github.com/dnnunn/zotero-auto-tagger.git
cd zotero-auto-tagger

# Install dependencies
npm install

# Build the plugin
npm run build

# Create .xpi file
cd build && zip -r ../zotero-auto-tagger.xpi * -x "*.DS_Store" && cd ..
```
